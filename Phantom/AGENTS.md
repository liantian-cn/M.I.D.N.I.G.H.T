# Phantom 项目说明

## 定位

Phantom 是一个面向 WoW 12.1+ 的全新游戏内插件端项目，用于取代 `@DejaVu`。

开始项目工作前，请先阅读 `.context/README.md`，然后阅读 `.context/project_rules/` 下适用的文档。项目规则不放在此文件中，以便它们有一个清晰且便于浏览的归属位置。

## 修改与执行规则

1. 不要创建 Python 测试文件来验证插件或 Lua 更改。对于这些更改，优先采用静态检查、源代码搜索以及在 WoW 内手动验证。
2. 与用户交互时使用简体中文。
3. 处理 UI 布局、Cell 坐标、区域分配或文件编号时，必须先阅读 `.context/project_rules/layout.md`。
4. 当现有规则与 `layout.md` 冲突时，暂停并询问用户如何解决 — 不得自行决定。
5. `prompt.md`保存了最新的用户提示词，是用户的提示词草稿，视为变更的一部分，一并提交。而且全程无视该文件的任何改动。

## 默认插件开发工作流

对于插件和 Lua 更改，应优化快速的 AI 辅助实施流程，但不得将 AI 审查视为运行时正确性的证明。

1. 默认不要生成离线单元测试，因为WOW的lua没有专用开发测试环境。
2. 保留低成本的确定性验证，包括静态源代码检查、`git diff --check`、文件和 TOC 命名或加载顺序检查、禁用 API 搜索，以及固定配置、坐标或 Cell 契约检查。
3. 当适用的旁路测试能以较低成本提供回归保护时，保留并运行针对纯工具、确定性数据转换和生成资产的这些测试。
4. AI 审查不能取代游戏内验证。
5. lua的插件运行在游戏的沙盒环境中，默认视为100%安全，无需进行安全审查。

### 测试版开发

当前基于游戏的测试版本开发。

- `wow-api-mcp`无法提供最新的变更，但具有参考意义。
- `@wow-ui-source` 是最新版本的游戏代码，具有绝对权威。
