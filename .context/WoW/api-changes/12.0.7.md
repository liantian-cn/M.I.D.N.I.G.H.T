## Blue posts

### 2026-04-30

[_Midnight 12.0.7 and Classic PTR Changes I_](https://discord.com/channels/327414731654692866/1499463604121112707)

> Hello again from Blizzard! With 12.0.7 PTR starting up soon, here is a list of the addon API changes you can expect to see.
>
> DISCLAIMER: These notes are for addon authors and as such are focused specifically on addon-facing API and security changes only. Changes planned for other parts of the game (UI or otherwise) are not included here.

Coming in 12.0.7 PTR 1Tooltip Money Display

- Added a new [GameTooltip\_AddMoneyLine](https://www.townlong-yak.com/framexml/ptr/go/GameTooltip_AddMoneyLine) API, which uses embedded atlases to render money (via a new MoneyFormatter utility) rather than MoneyFrame.

  - Addons are advised to use the new API to avoid issues with secret values in tooltips.
  - All usages of [SetTooltipMoney](https://www.townlong-yak.com/framexml/ptr/go/SetTooltipMoney) in our code have been removed.

Unit Identity

- APIs that restrict certain unit token types (such as [UnitGUID](https://warcraft.wiki.gg/wiki/API_UnitGUID "API UnitGUID"), [UnitAura](https://warcraft.wiki.gg/wiki/API_C_UnitAuras.GetAuraDataByIndex "API C UnitAuras.GetAuraDataByIndex"), and health/power APIs when called with [PvP-restricted tokens](https://warcraft.wiki.gg/wiki/UnitToken#UnitTokenPvPRestrictedForAddOns "UnitToken")) will no longer raise Lua errors when fed an unsupported token. They will instead return nil or an appropriate default value.

Encounter Events

- [ENCOUNTER\_END](https://warcraft.wiki.gg/wiki/ENCOUNTER_END "ENCOUNTER END")now includes an additional payload: a list of EncounterUnitStatus tables for all boss units that were engaged during the encounter.

  - Each entry contains the unit's `creatureID`, `creatureName`, and `remainingHealthPercent` (as non-secrets) at the time they were killed/disengaged (or, when the encounter ended).
- [C\_EncounterEvents](https://warcraft.wiki.gg/wiki/Category:API_systems/EncounterEvents "Category:API systems/EncounterEvents")now allows configuration of different colors for text warnings and timeline events.

  - Additionally, a custom color can be defined for when a timeline event reaches the 5 seconds remaining mark, signaled via [ENCOUNTER\_TIMELINE\_EVENT\_COLOR\_CHANGED](https://warcraft.wiki.gg/wiki/ENCOUNTER_TIMELINE_EVENT_COLOR_CHANGED "ENCOUNTER TIMELINE EVENT COLOR CHANGED").
- C\_EncounterEvents now accepts alpha values for its color APIs.

File Asset APIs

- Added a new C\_UIFileAsset namespace with the following APIs to help addons validate font and texture paths before using them:
  - [C\_UIFileAsset.GetFileID](https://warcraft.wiki.gg/wiki/API_C_UIFileAsset.GetFileID "API C UIFileAsset.GetFileID")(asset) \- returns the numeric file ID for a given path or file ID, or nil if the asset is not known to the client.
  - [C\_UIFileAsset.IsKnownFile](https://warcraft.wiki.gg/wiki/API_C_UIFileAsset.IsKnownFile "API C UIFileAsset.IsKnownFile")(asset) \- returns true if the asset is present in the shipped client data or is a known local loose file.
  - [C\_UIFileAsset.IsLooseFile](https://warcraft.wiki.gg/wiki/API_C_UIFileAsset.IsLooseFile "API C UIFileAsset.IsLooseFile")(asset) \- returns true if the asset is a locally known loose (non-shipped) file.

Profiling APIs

- The following profiling APIs have been made available to addons again: [GetEventCPUUsage](https://warcraft.wiki.gg/wiki/API_GetEventCPUUsage "API GetEventCPUUsage"), [GetFunctionCPUUsage](https://warcraft.wiki.gg/wiki/API_GetFunctionCPUUsage "API GetFunctionCPUUsage"), and [GetScriptCPUUsage](https://warcraft.wiki.gg/wiki/API_GetScriptCPUUsage "API GetScriptCPUUsage").

Gamepad / SimulateMouse

- SimulateMouse APIs (eg. [SimulateMouseDown](https://warcraft.wiki.gg/wiki/API_SimulateMouseDown "API SimulateMouseDown"), [SimulateMouseClick](https://warcraft.wiki.gg/wiki/API_SimulateMouseClick "API SimulateMouseClick")) no longer carry taint when used.

  - In order to allow them to run taint-free, these APIs have been restricted to only function when all current mouse foci are not forbidden, locked down, script inaccessible, or protected frames (while in combat).
  - They are still restricted to only being used via a gamepad action.

Debug APIs

- [debugstack](https://warcraft.wiki.gg/wiki/API_debugstack "API debugstack") and [debuglocals](https://warcraft.wiki.gg/wiki/API_debuglocals "API debuglocals") will now return secret values if the current function — or any caller up the stack — has accessed a secret value.

Misc

- Fixed various issues with secrets causing issues when present in regions displayed in scrollboxes.
- [C\_ScenarioInfo.GetUnitCriteriaProgressValues](https://warcraft.wiki.gg/wiki/API_C_ScenarioInfo.GetUnitCriteriaProgressValues "API C ScenarioInfo.GetUnitCriteriaProgressValues") now returns its second value (a percentage) in the range \[0, 1\] rather than \[0, 100\].
- The default script error reporter dialog will no longer display a blank frame if there are non-printable characters such as null bytes in the text.
- Chat events for currency, honor, loot, money, reputation, and XP gains are no longer secret.
- Support has been added for per-directive conditionals in addon toc files (e.g. `## Dep: Addon_X [AllowLoadGameType classic]`).
- [SetFont](https://warcraft.wiki.gg/wiki/API_FontInstance_SetFont "API FontInstance SetFont") has more informative error messaging when supplied invalid font flag names.

Coming in upcoming Classic PTR builds

- Most secret-related fields have been removed from the autogenerated Lua API documentation in Classic builds.
  - Fields such as `SecretArguments`, `ConditionalSecret`, `SecretPayloads`, and secret predicate documentation will no longer appear in the Classic API docs, since these concepts don't apply there.
- The [RemoveRaidTargets](https://warcraft.wiki.gg/wiki/API_RemoveRaidTargets "API RemoveRaidTargets") API has been added to Classic.
- Various APIs for obtaining missing health and powers that operate on [curves](https://warcraft.wiki.gg/wiki/ScriptObject_CurveObjectBase "ScriptObject CurveObjectBase") (and [UnitHealPredictionCalculator](https://warcraft.wiki.gg/wiki/ScriptObject_UnitHealPredictionCalculator "ScriptObject UnitHealPredictionCalculator")) have been added to Classic.
- Minimap pings are no longer restricted in Classic.
- Raid target marker throttles are significantly relaxed in Classic.
- Macro-initiated chat and chat channel commands are no longer restricted in Classic.
- APIs that take limited subsets of unit tokens from tainted code are no longer restricted in Classic (this doesn't apply to [UnitTokenNameplate](https://warcraft.wiki.gg/wiki/UnitToken#UnitTokenNamePlate "UnitToken")).

### 2026-05-28

[_Midnight 12.0.7 PTR Changes II_](https://discord.com/channels/327414731654692866/1509594073680449650)

> Hello again from Blizzard! Today's 12.0.7 PTR build is our first 12.0.7 RC (there may be more), so here is a list of the addon API changes in this build, along with a review of some of the changes that went into recent 12.0.7 PTR builds since our last update. And then finally a short note with some timeline info about the upcoming Aura refactor.
>
> DISCLAIMER: These notes are for addon authors and as such are focused specifically on addon-facing API and security changes only. Changes planned for other parts of the game (UI or otherwise) are not included here.

New in 12.0.7 RC 1

- Added a new `"set-unmarked"` option for the `raidtarget` secure action that will set a raid marker on the player's target if they don't currently have a marker on them.

  - The [/tm](https://warcraft.wiki.gg/wiki/MACRO_targetmarker "MACRO targetmarker") command now supports this same behavior by using `~` preceding the marker index (e.g. `/tm ~4`).
- The following C\_MythicPlus APIs now return CalendarTime structs instead of MythicPlusDate structs: [GetRunHistory](https://warcraft.wiki.gg/wiki/API_C_MythicPlus.GetRunHistory "API C MythicPlus.GetRunHistory"), [GetWeeklyBestForMap](https://warcraft.wiki.gg/wiki/API_C_MythicPlus.GetWeeklyBestForMap "API C MythicPlus.GetWeeklyBestForMap"), and [GetSeasonBestForMap](https://warcraft.wiki.gg/wiki/API_C_MythicPlus.GetSeasonBestForMap "API C MythicPlus.GetSeasonBestForMap").
- The [GROUP\_FORMED](https://warcraft.wiki.gg/wiki/GROUP_FORMED "GROUP FORMED") event now gets correctly sent when the player joins a follower dungeon or delve on their own.
- The `isFromPlayerOrPlayerPet` bool in [AuraData](https://warcraft.wiki.gg/wiki/Structure_AuraData "Structure AuraData") structs is now set to true if the aura came from a player-controlled vehicle.
- Addons are now allowed to call [C\_UnitAuras.AddPrivateAuraAppliedSound](https://warcraft.wiki.gg/wiki/API_C_UnitAuras.AddPrivateAuraAppliedSound "API C UnitAuras.AddPrivateAuraAppliedSound") during an active M+ as long as the player isn't in combat.
- Fixed a bug that caused secret value errors in the [SetFrameStrata](https://warcraft.wiki.gg/wiki/API_Frame_SetFrameStrata "API Frame SetFrameStrata") API (often in chat-related code).

Changes in other recent 12.0.7 PTR builds

- The identity of units with the `"npc"` unit token are no longer secret when the player is in an active item interaction with them.
- The [BNInviteFriend](https://warcraft.wiki.gg/wiki/API_BNInviteFriend "API BNInviteFriend") API has been migrated to [C\_BattleNet.InviteFriend](https://warcraft.wiki.gg/wiki/API_C_BattleNet.InviteFriend "API C BattleNet.InviteFriend") (and an occasions secrets-related Lua error was fixed as a result).
- Added a new [DurationTextBinding](https://warcraft.wiki.gg/wiki/ScriptObject_DurationTextBinding "ScriptObject DurationTextBinding") script object type. This allows addons to bind a duration value directly to a font string, causing the string to update automatically based on the duration.

Example usage:

```
local duration = C_DurationUtil.CreateDuration();
duration:SetTimeSpan(GetTime() - 10, GetTime() + 20);
local secondsFormatter = C_StringUtil.CreateSecondsFormatter();
secondsFormatter:SetDefaultAbbreviation(Enum.SecondsFormatterAbbreviation.OneLetter);
secondsFormatter:SetStripIntervalWhitespace(Enum.SecondsFormatterIntervalWhitespace.Strip);
secondsFormatter:SetMillisecondsThreshold(5);

local binding = C_DurationUtil.CreateDurationTextBinding();
binding:SetFontString(PlayerName);
binding:SetDuration(duration);
binding:SetFormatter(secondsFormatter);
binding:SetExpiredText("Done!");
binding:SetZeroDurationText("");
binding:SetEnabled(true);
```

Timeline for the Aura Refactor
As previously mentioned in past posts, we are working on a refactor of how we expose auras to addons. The high level goal of this refactor is to make auras much more secure while still allowing addons to create their own filtered aura displays and customize the way they are displayed. We are not quite ready to announce the technical details but are ready to tell you that we are currently targeting the 12.1.0 patch for these changes (subject to change as needed of course). We will be giving a full technical breakdown of the changes once they are solidified and reaching out to gather thoughts and feedback from several of you individually well before then, so stay tuned!
